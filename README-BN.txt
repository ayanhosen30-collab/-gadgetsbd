gadgets — Static website upload package

এই প্যাকেজে index.html আছে। এটি Firebase বা Admin Dashboard ছাড়া static storefront হিসেবে চলবে।

অর্ডার কীভাবে যাবে:
1. কাস্টমার পণ্য বেছে অর্ডার ফর্ম পূরণ করবে।
2. Confirm Order-এর পরে Telegram share window খুলবে।
3. কাস্টমার নিজে তোমার Telegram গ্রুপ/চ্যাট নির্বাচন করে Send চাপবে।

গুরুত্বপূর্ণ:
- Telegram-এ অর্ডার স্বয়ংক্রিয়ভাবে পাঠানো হয় না; কাস্টমারকে Send চাপতে হবে।
- এই প্যাকেজে Admin Dashboard, database, order history বা online payment নেই।
- লাইভ করার আগে HTML-এ পণ্যের দাম, যোগাযোগের তথ্য, ডেলিভারি চার্জ, bKash/Nagad বিবরণ যাচাই করো।
- Static deploy করার সহজ উপায়: https://app.netlify.com/drop খুলে এই ZIP-এর ভেতরের index.html-সহ ফোল্ডারটি আপলোড করো।
